# cgi-bin

Online .spl to .js/.st translators, see html/spl-to-{js, st}.html for form interface.

## spl-to-{js, st}.hs

- Translator from .spl to .{js, st}.
- Required to compile on a limited resource server (ghc 8.6.5, base libraries and split only).
- See <https://rohandrape.net/pub/stsc3/html/spl-to-js.html>
